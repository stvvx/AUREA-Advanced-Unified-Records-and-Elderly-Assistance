# 3D Avatar Animations Directory

This directory stores skeletal animation clips (`.glb` / `.bvh` / `.json`) for Lolo Pat:

1. `idle.glb` — Gentle breathing, micro-sway, and subtle eye gaze shift
2. `talking.glb` — Active speech body posture with hand gestures
3. `wave.glb` — Warm Filipino hand wave greeting
4. `thinking.glb` — Hand to chin thoughtful pose
5. `happy.glb` — Cheerful nodding and smile
